# Согласия в боте MAX — черновик на утверждение

Версия 0.1 — 15.10.2026. Решение по Q12 — вариант Г; Q18 закрыт: анкета «Мессенджеры»
в Медиалоге остаётся основанием для допуска (D4). Этот документ — для пациентов **без**
отметки в анкете: бот сам предлагает согласие. Тексты утверждает клиника (юрист /
ответственный за ПДн); Claude готовит черновик и техническую часть.

## 1. Когда бот показывает экран согласия

| Ситуация | Что делает бот |
|---|---|
| `MESSENGER_NOTIFY = 1` в Медиалоге | согласие уже есть — экран не показывается |
| `MESSENGER_NOTIFY = 0` (пациент отказался в анкете) | экран **не** показывается; бот отвечает только на прямые запросы пациента (анализы по запросу), напоминаний не шлёт. Изменить решение — через регистратуру |
| анкеты нет (`NULL`) и в боте согласия нет | после подтверждения телефона кодом — экран согласия (§2) |
| согласие в боте отозвано | напоминания прекращаются сразу; повторно экран — только по команде пациента |

> Открытый вопрос к клинике: показывать ли экран пациентам с отказом в анкете
> (`MESSENGER_NOTIFY = 0`) — по умолчанию нет.

## 2. Текст 1 — служебные уведомления (обязательный для напоминаний)

> **Уведомления о записях в MAX**
>
> Я подтверждаю, что номер телефона, на который пришёл код, принадлежит мне, и соглашаюсь
> получать в мессенджере MAX от [наименование медицинской организации, ОГРН, ИНН]
> служебные сообщения: о записи на приём, её изменении и отмене, напоминания о приёме и
> просьбы подтвердить визит, а также сообщения о готовности результатов исследований.
>
> Для этого клиника обрабатывает мои фамилию, имя, отчество, номер телефона, идентификатор
> в MAX и сведения о записях на приём (дата, время, филиал, врач или вид приёма).
>
> Согласие действует до отзыва. Отозвать его можно в боте кнопкой «Отключить уведомления»
> или заявлением в клинику. Отказ не влияет на оказание медицинской помощи.

## 3. Текст 2 — рекламная рассылка в мессенджере (необязательный)

Показывается **после** текста 1, отдельной кнопкой, без предварительной отметки.
Основа — форма клиники «Согласие на получение информации о программах лояльности,
акциях, спецпредложениях и других рекламных сообщений» (38-ФЗ, ст. 18 ч. 1), канал —
«сообщения в отечественных мессенджерах (МАКС и др.)». Паспортные данные не

## 4. Что хранит бот (техническая часть для LK-1e)

Таблица `consents` в `gateway.db` (Медиалог — только чтение, туда не пишем):

| Поле | Значение |
|---|---|
| `id` | ключ |
| `patient_id` | `PATIENTS_ID` из Медиалога (после подтверждения телефона) |
| `max_user_id` | идентификатор пользователя MAX |
| `kind` | `service` \| `ads` |
| `text_version` | версия текста (например `service-v1`), сам текст версии хранится в коде/конфиге |
| `accepted_at` | время согласия (UTC + отображение по Москве) |
| `revoked_at` | время отзыва или `NULL` |
| `source` | `bot` |

- Без ФИО и телефона в этой таблице: связь через `patient_id`.
- Отзыв — `revoked_at`, строка не удаляется (доказательство согласия и отзыва).
- Допуск к напоминаниям: `MESSENGER_NOTIFY = 1` **или** действующее согласие `service`.
- Реклама — отдельный будущий функционал; сейчас только сбор согласия `ads`.
- **Выгрузка для регистратуры** (вариант Г): раз в неделю список «пациент дал согласие в
  боте, в анкете отметки нет» — `PATIENTS_ID`, дата согласия, вид — чтобы администратор
  проставил анкету в Медиалоге. Формат и канал доставки (файл, письмо) — к инструкции
  регистратуре перед продом.
